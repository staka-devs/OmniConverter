# ADR-0001 アーキテクチャ決定記録の採用

- ステータス: 承認
- 日付: 2026-11-27

## 文脈
OmniConverter は多数のネイティブエンジンを組み込む。設計判断の理由が残っていないと、後から変更してよいかを判断できない。

## 決定
設計上の判断はすべて ADR として `docs/adr/` に残す。

- ファイル名は `ADR-NNNN-日本語タイトル.md` とする。
- 構成はステータス、文脈、決定、結果の 4 節とする。
- 判断を覆すときは既存の ADR を書き換えない。新しい ADR を追加し、古い ADR のステータスを「置換済み」にする。
- ADR は、その判断を実装するプルリクエストに含める。

## 結果
判断の経緯をリポジトリだけで追える。ADR を書く手間は増えるが、判断の重複や手戻りが減る。
