# ADR-0010 依存の配線は合成ルートで手で行う

- ステータス: 承認
- 日付: 2026-11-27

## 文脈
当初の計画では DI に Koin を使う予定だった。
しかし配線する対象は、リポジトリ、スケジューラ、エンジン一覧、数個のユースケースに限られる。

## 決定
DI フレームワークは使わない。`:app` の `AppContainer` でコンストラクタに渡して配線する。

- `AppContainer` は Infrastructure の実装を Domain のポートに結びつける唯一の場所とする。
- Presentation は `UseCases` を受け取り、ViewModel を生成する。Infrastructure の型は見ない。
- WorkManager のワーカーには、独自の `WorkerFactory` で依存を渡す。
- Room などの Infrastructure 内部の型は、合成ルートにも公開しない。

## 結果
依存関係がコードを読めば追える。注釈処理やリフレクションが要らない。
配線の対象が大きく増えたら、DI フレームワークの導入をあらためて検討する。
