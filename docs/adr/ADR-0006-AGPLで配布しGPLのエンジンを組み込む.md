# ADR-0006 AGPL で配布し GPL のエンジンを組み込む

- ステータス: 承認
- 日付: 2026-11-27

## 背景
高機能を目指すには、x264 や x265 を含む FFmpeg の GPL ビルド、AGPL の MuPDF、GPL の pandoc が必要になる。
これらを組み込むと、アプリ全体を同じ条件で配布しなければならない。

## 決定
アプリを AGPL-3.0 で公開し、GPL と AGPL のエンジンを組み込む。

- FFmpeg は `--enable-gpl --enable-version3` でビルドする。
- 配布物には、各エンジンのライセンスと、対応するソースの入手先を添える。
- ソースの入手先は、このリポジトリと `native/versions.sh` に記した版で示す。

## 結果
主要なコーデックとエンジンを制限なく使える。
アプリのソースは常に公開する必要があり、非公開の派生版は作れない。
ライセンス文書はネイティブのビルド時に集め、APK の assets/licenses とリリースの licenses.zip に入れる。手順は ADR-0012 にまとめる。
