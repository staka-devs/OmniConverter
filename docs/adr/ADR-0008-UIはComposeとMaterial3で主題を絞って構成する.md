# ADR-0008 UI は Compose と Material 3 で主題を絞って構成する

- ステータス: 承認
- 日付: 2026-11-27

## 背景
このアプリの主題は、ファイルを選んで別の形式にすることである。高機能を目指すほど画面に要素が増え、主題が埋もれやすい。

## 決定
Jetpack Compose と Material 3 の最新版で UI を作る。画面は主題に沿って絞る。

- 画面は「変換」と「キュー」の 2 つとし、下部のナビゲーションバーで切り替える。
- 変換画面では、ファイルを選ぶ前はファイル選択のボタンだけを中央に大きく置く。
- ファイルを選んだ後は、ファイル一覧、カテゴリ別の出力形式、変換ボタンだけを置く。
- キュー画面は、ファイル名、変換先、進捗、結果だけを表示する。
- 説明文は置かない。操作と状態だけで伝える。
- Android 12 以降は Dynamic Color を使い、エッジツーエッジで表示する。
- アイコンは使う分だけをベクター素材として持つ。アイコン集のライブラリは使わない。

## 結果
初めて開いた人も、次に何をすればよいか迷わない。
上級モードのような機能は、主題の流れを崩さない場所に追加する必要がある。
