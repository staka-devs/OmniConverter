# ADR-0011 pandoc は公式の静的バイナリを同梱する

- ステータス: 承認
- 日付: 2026-11-27

## 文脈
pandoc は Haskell で書かれている。GHC で Android 向けにクロスコンパイルするのは手間が大きく、保守も難しい。
一方で、pandoc は Linux 向けの arm64 静的バイナリを公式に配布している。

## 決定
pandoc はソースからビルドせず、公式の arm64 静的バイナリを同梱する。ADR-0005 の例外とする。

- `native/versions.sh` に URL と SHA-256 を記し、取得時に検証する。
- aarch64 で静的リンクであることを確かめてから置く。
- 動的リンカを通らないので、PIE でなくても Android で起動できる。
- アプリのプロセスには HOME と一時ディレクトリが無いので、作業ディレクトリを環境変数で渡す。
- PDF は直接出力しない。HTML を経由して MuPDF で組む。LaTeX を同梱しないためである。

## 結果
少ない手間で pandoc の全機能を使える。
バイナリはおよそ 174 MB あり、アプリの容量の大半を占める。
x86_64 のエミュレータのうち API 32 以前の ARM 変換は、静的バイナリのシグナル設定に対応せず起動できない。実機と API 33 以降のエミュレータでは動くので、その環境に限って pandoc の端末テストを飛ばす。
将来 Android の制限で静的バイナリが動かなくなった場合は、Termux のビルド手順を参考にソースからのビルドへ切り替える。
