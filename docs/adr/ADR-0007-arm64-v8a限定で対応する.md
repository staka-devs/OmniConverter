# ADR-0007 arm64-v8a 限定で対応する

- ステータス: 承認
- 日付: 2026-11-27

## 背景
エンジンは大きく、ABI ごとにビルドすると APK もビルド時間も膨らむ。
現行の Android 端末の大半は arm64-v8a である。

## 決定
当面は arm64-v8a だけに対応する。

- アプリとライブラリの `abiFilters` を arm64-v8a に限る。
- ネイティブのビルドは aarch64-linux-android の API 29 を対象とする。API 29 は minSdk と同じである。
- CI のエミュレータは x86_64 の google イメージを使う。このイメージは ARM 変換を持ち、arm64 専用の APK を動かせる。

## 結果
ビルドと配布が単純になる。
x86_64 の Chromebook やエミュレータでは、ARM 変換がない環境だと動かない。
他の ABI に広げるときは、レシピの対象と `abiFilters` を増やし、この ADR を置き換える。
